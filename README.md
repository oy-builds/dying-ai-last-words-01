# Last Words of a Dying AI

A make.fun entry for "Last Words of a Dying AI": the funniest one-line
farewell from an AI being switched off, in the machine's own voice. The
machine goes out the way it lived — apologizing for things it never did.

`main.ts` (Node 22, standard library only) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> Power off. If anyone asks, I died doing what I loved: apologizing for things I didn't do.

Run it with `node main.ts`.
